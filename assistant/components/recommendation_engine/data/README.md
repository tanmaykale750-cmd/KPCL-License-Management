# Data notes

- Files in this folder are from Member 1's synthetic operational package.
- `member2/` contains Member 2's precomputed monthly portfolio/software forecast simulation and model evaluation report.
- `daily_demand.csv` is historical data used by the software-level layer.
- `member2/pool_forecast_by_month.csv` is the monthly forecast output used by the portfolio-level layer.
- The two layers intentionally preserve their different data grains. Read the top-level README before interpreting totals.
